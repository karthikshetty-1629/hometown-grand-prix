San Jose map data

© OpenStreetMap contributors, Open Database License. Detailed road, one-way, speed-limit, crossing, signal, sidewalk, and tree tags were downloaded using Overpass API. The cached snapshot is used locally.

Signal nodes represent traffic control locations, not necessarily hardware coordinates. Pole offsets are derived and collision-checked. Road widths and speed limits use estimates where tags are absent. The HUD marks estimated speed limits with “est.” Building footprints come from the earlier OSM extract; facade appearance and missing heights are approximations.
